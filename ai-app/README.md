# AI Slide — AI App for AICoworker

PowerPoint-style editor (AI App) whose file engine is this repository's DeckCraft engine,
compiled to WebAssembly (`crates/wasm-core`). Install: `scripts/install-ai-slide.sh`.
Maintenance and the Rust self-healing flow: `../MAINTAINING-AI-SLIDE.md`,
`ai-slide/ENGINE-REPAIR.md`.
